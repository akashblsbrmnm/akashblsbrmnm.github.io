# Portfolio - Vue.js

A modern, lightweight portfolio website built with Vue.js 3 and Vite, featuring a stunning black and orange color scheme.

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm preview
```

## 🎨 Features

- ⚡ **Lightning Fast**: Built with Vite for instant HMR
- 🎯 **Lightweight**: Vue.js for minimal bundle size
- 🎨 **Modern Design**: Black background with vibrant orange accents
- 📱 **Fully Responsive**: Mobile-first approach
- ✨ **Smooth Animations**: Micro-interactions and hover effects
- 🌟 **Glassmorphism**: Modern UI effects
- ♿ **Accessible**: Semantic HTML and ARIA labels

## 🛠️ Tech Stack

- Vue.js 3
- Vite
- CSS3 (Pure CSS, no frameworks)
- Google Fonts (Inter, Space Grotesk)

## 🎨 Customization

Edit colors in `src/style.css`:

```css
:root {
  --color-bg: #0a0a0a;
  --color-accent: #ff6b35;
  --color-accent-hover: #ff8555;
}
```
